RSS Prarthana is the main origin and strength for swayamsvikas to achieve their goal. This is an app which can used to practice the RSS prayer by seeing prayer text in Telugu, Hindi, and English languages. Sangh prayer contains 3 shloka's which is written in sanskrit language, first shloka tells about the meaning of Rashtriya, second shloka tells about the meaning of Sevika and third shloka tells about the meaning of Samiti . This app can be used for those who recently joined RSS swayamsevikas to learn sangha prarthana and it's meaning.
